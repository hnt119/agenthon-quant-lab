# Example price data

The v0.3 historical example uses 91 daily Bitstamp BTC/USD observations from April through June 2025. Each UTC day uses the first open and last close of the positive-volume minute bars in the pinned source. The daily adaptation is distributed under CC BY 4.0. Preserve the dataset credit when redistributing it. [Source, attribution, extraction and hashes](bitstamp/README.md)

## Synthetic demonstration prices

`synthetic_prices.csv` is an original, redistributable fixture generated by
`../../scripts/generate_synthetic_data.py` with seed **20261114**. It contains
180 weekday session labels starting 2025-01-02, opening and closing prices,
fixed drift regimes, deterministic oscillation, and pseudorandom noise.
Dates do not apply an exchange holiday calendar. There are no market
observations, splits, or dividends. The data is covered by the repository's
license. It is not a market dataset or evidence of a strategy's profitability.

Regenerate from the repository root:

```sh
python scripts/generate_synthetic_data.py
```

The example fixes a 20-observation mean, 5 bps fees, 5 bps adverse slippage,
development through 2025-06-18 and holdout from 2025-06-19 before running the
simulation. No parameter search is performed. The period labels demonstrate
chronological evaluation mechanics; synthetic holdout performance does not
validate a market hypothesis. The test suite regenerates the file and checks
byte equality.
