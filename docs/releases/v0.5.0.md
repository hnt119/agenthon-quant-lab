# Agenthon Quant Lab v0.5.0 distribution

The stable Python package adds a fourth offline BTC study. Restoring BTC to a 50% target on positive-signal Mondays reduced maximum drawdown from 64.45% to 45.02% relative to funding half the weekly strategy and holding the remaining $5,000 in cash. The target finished with $25,334.67 versus $29,342.96. The paired conditional 95% interval for the 19.43 percentage-point reduction was +0.66 to +23.82 points. All four studies reuse the previously examined 2020–2024 history and minute-candle execution proxies. [Research report](../../reports/btc-weekly-allocation-v1/README.md) · [Frozen protocol](../../experiments/btc-weekly-allocation-v1/protocol.json)

Use an activated Python 3.12+ virtual environment and fresh output folders. The four commands work offline after installation.
