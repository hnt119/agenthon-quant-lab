## Install from PyPI

In an activated Python 3.12+ virtual environment, run these commands from a writable directory.

```sh
python -m pip install agenthon-quant-lab==0.3.1
quant-lab doctor
quant-lab btc-study
```

The command prints paths to the report, offline dashboard and reproduction receipt. The optional Codex skill requires a source checkout. [Skill installation](../plugin-guide.md)

| CLI path | Installed input and output behavior |
|---|---|
| `--version`, `doctor` | Identify the version, installation mode, local resources, dependencies and optional skill. Wheel runs record a null Git revision. |
| `btc-study` | Load the protocol, snapshot, attribution, original receipt and eight saved outputs from the installed package. Verify both source inventories and reconstruct into a fresh folder. |
| `example options/trading/historical` | Load the three bundled specifications, synthetic CSV or Q2 Bitstamp CSV. Resolve example data alongside its specification. |
| `archive papers/experiments` | Search bundled, curated public JSON. Historical paths and experiment IDs are citations. |
| `run`, `inspect-data` | Read the user’s local specification and its relative data path. |
| `reproduce`, `explain`, `verify-inputs`, `bundle` | Use a user-selected run folder. Generic reproduction requires matching source fingerprints. Bundles carry private inputs and provenance. |

The original protocol and receipts keep their v0.3.0 identities. The [compatibility record](../../packaging/btc-compatibility.json) binds the original source map and the exact ported map, including the new resource loader. An unknown source map fails verification. Each fresh BTC receipt identifies the compatibility record. Compare its eight output hashes, followed where applicable by the original structured numerical comparison. The chart still requires byte identity. [Study report](../../reports/btc-financial-v1/README.md) · [Data notices](../../DATA-NOTICES.md)

## Qualification evidence

The public-index replay on macOS arm64 with CPython 3.12.7, NumPy 2.5.4 and SciPy 1.18.1 reproduced all eight principal outputs byte for byte. The prepublication macOS CPython 3.13.15 run also reproduced all eight exactly. Linux CPython 3.12.16 passed the installed workflows with six byte-identical outputs and two numerically equivalent outputs within the original tolerances. Qualification exercised the built distributions outside a source checkout. Platform coverage is limited to the environments tested.
