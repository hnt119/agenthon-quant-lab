## Bounded methods review

| Question | Evidence and finding |
|---|---|
| Did the protocol precede the result? | The freeze precedes both the numerical implementation commit and the UTC start in the receipt. Selection used eight complete years by coverage. The later pilot had already been examined when the protocol was designed. |
| Was the passive comparator executable? | Each January allocation uses only valid closes through the preceding Dec 31. It targets that training fraction after costs and drifts until the next annual rebalance. Only five fills occurred. Every observed target was strictly between zero and one. |
| When could a trade occur? | At midnight UTC the preceding close was complete. The base price was the first positive-volume minute opening price at or after 00:05. This leaves a decision-to-price delay. Exact transaction time, spreads and depth are unavailable. |
| Did books and fees carry across folds? | The generator creates one continuous portfolio per scenario. Independent replay compares post-cost exposure, charged fees, signed holdings, cash, closing equity and compounded returns on every session. Entry, exits and annual rebalance fills pay the same one-way cost convention. |
| What did the bootstrap compare? | The investment endpoint is a **difference of pooled net Sharpes**, using matching dates for both strategies. The predictive endpoint is the difference between mean delayed quote-to-quote returns in two prior-close signal states. It discards each year's boundary-crossing label. Within each year, 20-session circular blocks resample the paired observations. Each endpoint gets its own draws, 4,000 in total per endpoint. Intervals condition on the fitted settings and five observed years. |
| Which checks are independent? | The verifier reconstructs signals using direct Fourier sums and checks recorded fills against source quotes, cash conservation and achieved targets. It separately recomputes returns and risk summaries. Bootstrap replay uses the same resampling implementation. It tests reproducibility. The matched-pair fixture tests the resampling identities. |
| Can others reproduce it? | The bundled extract is adapted from the historical publication of Kaggle v706 under CC BY-SA 4.0. The publisher identifies the upstream source and distinguishes its later API segment. Attribution, version, selection, changes, hash and license are shipped. The raw minute archive is optional. [Source manifest](../../experiments/btc-financial-v1/source.json) |
