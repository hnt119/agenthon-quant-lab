## What crosses the boundary

The new runtime is a small, separately versioned package. It carries documented conventions, numerical and accounting patterns, independently authored synthetic fixtures, and references to historical work. It does not carry the original Git history, submission ZIPs/images, team proofs, private captures, grader/reference material, canary data or generated competition solutions. See [attribution and material boundaries](attribution.md).

The old repository remains the historical evidence archive. To inspect a source identity there, use `git show <full-commit>:<relative-path>`; a source commit is distinct from a source fingerprint, OCI config ID, image manifest digest, descriptor digest or ZIP hash.
